# Build workspace

This directory is for generated, non-authoritative working artifacts.

Canonical manuscript membership and order come from `governance/CHAPTER_LEDGER.yaml`, not filesystem enumeration.

Use:

`python tools/assemble_manuscript.py`

to generate a working Markdown assembly and machine-readable manifest.

Generated files in this directory are not publication artifacts, do not change chapter lifecycle status, and do not imply certification or release authorization.
