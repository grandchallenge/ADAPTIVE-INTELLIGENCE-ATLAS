# ATLAS-CH-THESIS-001 — Documentary Synthesis Packet

## Status

Atlas synthesis, not theorem.

## D1. Source-inventory recurrence

The seed inventory repeatedly shifts emphasis:

- vectors -> operators;
- layers -> flows/integrators;
- parameters -> geometry;
- depth -> computational time;
- routing -> online decision making;
- context -> compiled memory access;
- agents -> distributed systems;
- training -> dynamical identification;
- interpretability -> intervention and substitution;
- architecture -> composition of contracts;
- research result -> replayable evidence object.

These shifts are project-scope evidence for the monograph's organizing thesis. They are not independent external validation.

## D2. Minimal thesis

The bounded thesis is:

> Adaptive intelligence is treated in this Atlas as organized computation over states, operators, dynamics, memory, interfaces, evidence, and governance.

This is deliberately weaker than:

> all intelligence is nothing but these objects.

The stronger ontological claim is not made.

## D3. System decomposition

The Atlas uses the explanatory decomposition

[
mathcal A
=
(mathcal S,mathcal O,mathcal D,mathcal M,mathcal I,mathcal E,mathcal G),
]

where the symbols denote state, operators, dynamics, memory, interfaces, evidence, and governance roles.

This tuple is not proposed as a canonical external mathematical object. It is an orientation device that later chapters refine.

## D4. Falsification / pressure points

The thesis would be weakened if major adaptive capabilities repeatedly required structures that cannot be usefully represented through the proposed roles, or if the decomposition obscured more than it clarified.

The book therefore treats later chapters as tests of the thesis, not illustrations chosen to guarantee it.

## Claim boundary

This packet reconstructs how the Atlas thesis follows from the project inventory and architecture. It does not prove a theory of intelligence.
