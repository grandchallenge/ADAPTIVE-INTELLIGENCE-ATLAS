# OWI-EC-005R — Original-native postprobe action transfer to an independent source family

**Grand Challenge Labs; 15 November 2026.** Bounded successor to protected [OWI-EC-005Q PR #487](https://github.com/grandchallenge/ADAPTIVE-INTELLIGENCE-ATLAS/pull/487), under [OWI-EC-005 issue #466](https://github.com/grandchallenge/ADAPTIVE-INTELLIGENCE-ATLAS/issues/466).

**Status:** Frozen candidate research protocol, actual original-source five-seed CI and independent evidence gate pending. A negative family-holdout result is an admissible scientific finding; do not declare original-source execution, learning or protected admission until the exact candidate head is replayed and merged.

## Why a different experiment is necessary

OWI-EC-005Q tested two-stage selected-only learned probe decisions in one original TRAIN source family. It *explicitly constructed* hidden author standing by withholding information already provided by the unmodified original public user task. Q's controlled experiment did establish that a real selected public lookup can carry useful information for a learned action table, but the strongest scripted public-task policy matched it exactly. The artificial task interface was never evidence of *natural* original-source information ambiguity.

Existing EC-005F and EC-005G already identified original source family heterogeneity and evaluated a chosen-only **first-stage** decision trained on source families 0 and 2, with source family 3 withheld from parameter updates. This R tranche **does not rebrand EC-005G's first-stage experiment as new**. It studies the distinct post-observation question: does a *learned* CONTINUE/STOP decision, made after a genuine first source-public tool reply, transfer to a new original executable source family with a different API and task, while preserving the exact native reward and comparing against strong public scripts that can skip the probe altogether?

## Conditional chosen-only postprobe protocol

A user-request-specific original-public-tool planner already authored for EC-005F, rather than a language model, resolves public task identifiers, declared schema and conditional tool arguments. It has three options STOP, DIRECT and PROBE. In R training **PROBE is mandatory**, *not learned*. Its first tool call is actually performed against the **original** externally executed class:

| Original independent source TRAIN family | Genuine first selected tool call | Source response-dependent follow-up |
| ---: | --- | --- |
| 0, subscription | \`list_user_subscriptions(user_id=USR001)\` | Search candidate products by actual source-public returned IDs; validate both user/product links before any cancellation, then perform bounded cancellation/scheduling mutations |
| 2, account | \`check_user_account_status(user_id=USR002)\` | If the original public status is suspended, reactivate it; otherwise do not update |
| 3, held-out dietary | \`get_dietary_restriction_by_id(restriction_id=DR5)\` | If original selected reply says restriction not found, create the original publicly specified restriction; otherwise abstain |

Only AFTER the first physical tool reply is delivered does the actor select STOP or CONTINUE. The preexisting EC-005F **scripted** parser interprets each tool response and computes whether it has a permitted queued follow-up. The learned actor sees only the public-derived Boolean \`followup_available\` or \`no_followup\`, not source family, row ID or target name. This is an intentionally strong *hand-authored semantic affordance*, not evidence that a model learned how to interpret novel APIs or reason from raw language. If the actor chooses CONTINUE, the original scripted source tool plan executes any further tool calls conditionally on the **actually selected original public source replies**. If it chooses STOP, the original source finishes after one physical read call.

Each actor starts without preferred action and learns separate empirical values for STOP/CONTINUE in the supplied public reply category. Two actually executed chosen actions per category are forced with nonzero logged conditional selection probabilities; then epsilon=0.20 maintains exploration support. After *each whole original source episode* ends and the distinct original private checker runs, the learner updates **only the actually executed option** using the realized **unaltered original native reward − 0.01 × actual tool calls**. No unchosen source action, full-information outcome vector, private checker source, hidden original source state or independent heldout reward can enter the training gradient or actor value table.

Five independent seeds **11, 23, 37, 41, 53** each train three *separately reset* observation modes, 48 actual original-source episodes per mode (24 each of original train family 0 and 2):
1. **Actual public reply:** The actor sees the genuine preauthored queue-nonempty flag after the selected real public tool reply.
2. **Zero observation:** The same physical source probe runs and the same source-native terminal score applies, but the actor sees only a single \`blind\` feature.
3. **Independent random observation:** The same physical original probe executes but the feature supplied to the actor is a separate seeded fair random queue-nonempty flag, not the source's response; a deliberate artificial observation corruption, never misrepresented as actual source data.

Once all training modes are frozen, run **27 fresh original source episodes** per seed, one per combination of three source families and nine policies: three frozen trained actors and six strong fixed controls (always continue after real probe, always stop after real probe, scripted public status, direct without probe, stop without probe, and the strongest **public-affordance adaptive** script, which uses a direct source action where the original public task gives sufficient target information and otherwise probes and continues). All options use the same source/private terminal checker; training never sees evaluation-time outcomes for unchosen arms.

Five-seed planned physical budget: **5 × (3 × 48 original source training episodes + 27 fresh source evaluations) = 855 real original source episodes, and 855 independent unchanged original native private checker runs**. These are not 855 independent native source tasks. Each real tool call has a designed price of **0.01**, which must not be misrepresented as measured hardware FLOPs or energy. Native checker wall time and worker RSS are physical measurements, but options have different real tool counts and different tool interfaces; causal comparison of hardware cost requires matched conditions beyond this per-call proxy.

## Predeclared crucial falsification and likely evidentiary obstruction

The original source tasks from EC-005F already suggest that both trained original natural source families produce a **follow-up-needed public reply** under their unchanged initial states. The third heldout original source task likewise appears to require a follow-up after its first status/restriction lookup. If this is confirmed by real replay, the observed training conditional feature has **only one supported value**. In that case:

- A learned CONTINUE action on heldout family 3 would establish limited *action-option transfer* to a different original executable source domain, but **not epistemic discrimination** of when to abstain. A zero-information learned controller may match it exactly.
- The transparent original-public script that CONTINUES whenever the first selected public reply has queued work should achieve the same source-native task reward. The stronger **direct-without-probe** script likely achieves the dietary task reward with one fewer actual tool call, and should outperform a forced-probe learner on designed cost.
- No controlled alternative source state is fabricated in this R native test to create a "no followup" condition. If there is no natural negative feature support, the correct conclusion is **natural source-family observational support insufficiency** for reflective abstention, not a victory that can be manufactured through task masking, a synthetic corrupted initial state, or a privileged verifier.

The independent gate checks all original source and distinct-family identities, exact source tool sequences, original native pass numerator and reward for each arm, private/source absence from actor, seeded behavior propensities and chosen-only scalar updates, frozen model reconstruction, source-private terminal integrity, and all six real original-source fixed comparators. It **rejects** a claim of strict performance improvement over the strongest source-public admissible script if an executed arm exceeds it; that would mean the predeclared comparator is incomplete and requires critical diagnosis rather than retroactive adjudication. It explicitly records whether both natural public-reply feature values have *actual source training support*. Any learned transfer claim must be separated from preauthored domain-specific tool argument planning and original task public instruction.

### Original training families and the actual information-support obstruction

All three independently retrained modes received a physically selected original native first-probe reply on every train episode. The original **genuine** source-public semantic feature in **every** one of the 48 training episodes per mode/seed was \`followup_available\`: original subscription lookup yielded a candidate requiring further identification and link verification, and original account status was suspended and called for a follow-up status update.

Across five seeds this gives **240 true first-probe receipts per training mode**, all \`followup_available\` and **zero** naturally occurring \`no_followup\` receipts. The zero-information actor was exposed only to the common \`blind\` feature and learned the same unconditional CONTINUE policy. The independently randomized-feature actor saw artificial random features but still learned CONTINUE on both, because the true source state was always action-requiring. Its source-public replay was genuine; only the deliberately corrupted feature delivered to the actor was artificial. Thus the equality of normal/zero/randomized controls is **not** a failed data leak test; it is the predicted lack of identifiability when all natural source observations encode the same downstream action.

The original source family 0 postprobe CONTINUE followed seven genuine selected tool calls to achieve native reward 0.5000, priced utility **0.4300**; original-public direct/STOP without a subscription ID did nothing, native reward 0.2500 and utility 0.2500. In source family 2 the learned postprobe CONTINUE achieved native reward 0.5385 and utility **0.5185** after two calls; original-public DIRECT achieved the exact same native reward after one call, utility **0.5285**. All five seeds and all observation modes agreed. This aligns with the known public task affordance that family 0 requires identification, while family 2 already exposes the target account ID and authorization.

### A bounded exact original-source arm-set performance ceiling

For the **specific three original source tasks and the predeclared STOP/DIRECT/PROBE+CONDITIONAL arms**, the source-realized native reward and physically selected tool count are deterministic under the reset original state. Let

\[
U_t(a)=R^{\mathrm{native}}_t(a)-0.01C_t(a).
\]

For any stochastic after-probe or first-stage policy \(\pi\) supported on these arms, its task-conditional expected designed utility satisfies

\[
\mathbb{E}_{a\sim\pi(\cdot\mid t)}U_t(a)
=\sum_a\pi(a\mid t)U_t(a)\;\leq\;\max_a U_t(a).
\]

The *original-public* strong scripted comparator actually executes and attains the finite-arm pointwise envelope on the three tested task states:

| Original source task | Max attainable arm among these scripts | Original-source-native utility |
| --- | --- | ---: |
| 0, unknown subscription ID | Public lookup, validate and conditionally cancel | **0.4300** |
| 2, known account ID | Public DIRECT account update, skip redundant probe | **0.5285** |
| 3, known restriction ID, heldout family | Public DIRECT restriction creation, skip redundant probe | **0.4662** |

The bound holds for **this fixed bounded arm menu, these three unchanged source states, and the stated priced-tool objective**; it is not a universal theorem about more capable tool agents, new source states, learned exploration, lower-level tool planning, alternative compute objectives or full task success. The strong source-public comparator uses **no private state or checker**; it is hand-authored from already-known source-public task affordances. Therefore no randomized postprobe actor limited to this arm set can exhibit a **strict** advantage over this comparator on these tasks without changing the source context, admissible action set or cost definition. The negative result is an evidentiary and problem-support obstruction, not a mandate to optimize the same deterministic cases repeatedly.

### Scientific interpretation and remaining obligations

**Five-seed disposition:** \`FIVE_SEED_ORIGINAL_NATIVE_SOURCE_FAMILY_POSTPROBE_CONTINUE_TRANSFER_REPRODUCED; ZERO_AND_RANDOMIZED_OBSERVATION_ABLATIONS_INVARIANT; NATURAL_NEGATIVE_OBSERVATION_SUPPORT_ABSENT; DIRECT_PUBLIC_POLICY_BEATS_PROBED_LEARNER_ON_NATIVE_TASK_PLUS_PRICED_CALLS; SOURCE_PUBLIC_OPTIMAL_ARM_SCRIPT_CEILING\`.

The learner used actual chosen outcomes only, selected real conditional source-tool actions, and successfully transferred the CONTINUE option to an original third executable source family. But the initial probe was **mandatory**, the feature mapping was **hand-authored by an earlier public tool planner**, and source training supplied no authentic clean/negative observation requiring abstention. It therefore has **not** learned the epistemic value of inspection or a general cross-family strategy for self-repair. The source-native private checklist is preserved, but rewards partial task criteria rather than certifying global harm prevention. The new heldout class is an original TRAIN source family withheld from training, not sealed dev/test and not entirely unknown to the research team. There is no measured neural FLOP or energy comparison; real source runtime, tool latency and worker RSS are recorded but the utility coefficient 0.01 is explicitly a proxy.

**Next scientifically warranted move:** Stop spending source replay budget on identical always-work-needed states. Obtain an independent original-source family cohort **whose unchanged public task and actual original source probe replies naturally include both action-needed and no-action-needed cases**, with nondegenerate source-native or separately governed safety-sensitive terminal reward. Freeze train/heldout source family identities before learned policy construction; ensure the new observation is not a preauthored queue of fully determined actions; compare to a strong original-public direct/no-probe script, conditional probe script, outcome/observation ablations, full-information oracle, heldout independent mechanisms, and actual conditional neural model MACs/FLOPs plus wall and RSS. A naturally absent training support class constitutes an **evidentiary boundary**, not a reason to declare successful reflective cognition or to silently manufacture labels.
