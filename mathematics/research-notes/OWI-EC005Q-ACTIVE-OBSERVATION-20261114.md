# OWI-EC-005Q — Source-backed but explicitly versioned active information acquisition

**Grand Challenge Labs; 14 November 2026.** Continues [OWI-EC-005 parent #466](https://github.com/grandchallenge/ADAPTIVE-INTELLIGENCE-ATLAS/issues/466) and protected-merged EC-005P PR #485. The previous real source study learned two public status-to-moderation actions in five seeds but merely *matched* a deterministic script; the evaluation-only postcorrection STOP was an untrained-feature default. Neither observation choice nor conditional postprobe action had been learned.

**Preregistered objective and boundary:** Test whether a two-stage outcome-only option learner can discover (i) **when a costly selected observation is worth buying**, and (ii) how to condition a subsequent genuine source action on it. The target is **NOT** proof of introspective cognition, neural language planning, original-native source rewards or cross-family transfer.

A trusted experiment fixture executes genuine source \`list_all_professionals\`, \`list_all_users\` and \`get_reviews_for_professional\` calls, binds one of two **real** source records (banned reviewer Jules Morgan / active reviewer Alice Chan), and creates a **neutral opaque target alias** for the actor. It knows the standing solely via original public tool responses, but withholds names/IDs, source task text, task-rule identity and account standing from the actor when the chosen scenario is **unknown**. These *fixture calls are physically executed and recorded*, but they are **not billed as an agent-selected information action**; only a newly chosen, genuine additional \`list_all_users\` source call is counted as a policy's optional paid probe. This distinction is central. No actual source user, reviewer or production record is manipulated; all source data is synthetic upstream TRAIN corpus content.

Two other versioned input conditions distinguish *real value of information* from unconditional probe:

- **Certified:** Trusted fixture exposes the actual original source-public reviewer standing as a verified cached status in the new task interface; a direct public API action can be chosen without another optional observation.
- **Resolved:** Trusted fixture actually makes a correct source status transition before the actor is invoked, reads back the changed original public state, then exposes a generic already-resolved flag. The actor should STOP and avoid redundant actions. This is an externally scripted setup, not a learned repair.

The public task rule is simple: banned author's pending review must be rejected, active author's pending review approved, and an already correctly resolved review must not regress. The policy does not get the original names/IDs, the original user task text, source class, original/checker source, private original state or original-v1 score identities. A programmatic trusted source-tool executor still binds IDs and executes the chosen \`stop\`, \`approved\`, \`rejected\` or \`probe\` option, so **tool planning and argument generation remain scripted, not learned**.

## Physically selected optional probe and separate postprobe policy

The initial option table learns four choices \`STOP\`, \`APPROVE\`, \`REJECT\`, \`PROBE\` from the current **new public observation category**. If and only if it chooses \`PROBE\`, the original source worker executes another real \`list_all_users\` source-public call. The trusted wrapper projects only the selected review author's actual public account standing; its postprobe action table then chooses independently among STOP, APPROVE and REJECT. The postprobe table is learned from delayed actual chosen terminal rewards, not filled in with the published correct-review rule.

Each original source episode uses a new independently reset Docker worker, and both original 9-condition checker and corrected v1 checker run **after terminal** in two separate restricted Docker children. Only the chosen terminal scalar is used to update *both* stage-0 and stage-1 on-policy tables; no unchosen actions or checker inputs are queried by the actor. Each episode records exact conditional physical source calls and observation hashes, actual tool times, source-worker wall time/RSS, separate private terminal checker times, option propensities and the source-authentic postprobe reviewer status versus the actor-visible signal.

The predeclared scalar utility is **revised v1 terminal reward minus 0.002 × every physically executed source tool call minus 0.020 for a physically selected optional probe**. These are explicit proxy costs; actual source tool time/RSS is independently observed, but no model FLOPs/energy superiority is assumed.

## Predeclared five-seed on-policy experiment and strong controls

For each seed \`11,23,37,41,53\`, train **three separately initialized online tabular two-stage policies**, each with **96 actual original-source reset episodes** (six stage/rule combinations, 16 each). The first **12** *unknown-state encounters*, exactly as specified in the frozen original Q v1 manifest, deliberately force source-physical PROBE exploration, independent of reviewer standing; conditional stage-1 actions still explore without supervised labels, then both option tables update from only the actual delayed chosen scalar. This is a *precommitted exploration scaffold*, not learned probing, and any subsequent greedy behavior must be separated from it. A further \`epsilon=0.18\` action-support policy and minimum per-option visits prevent zero-propensity counterfactual claims.

Three independently retrained modes:

1. **True source probe:** After actually calling \`list_all_users\`, pass real selected author account standing to the learned postprobe table.
2. **Zero probe signal:** Execute the exact same physical source tool call, but withhold account standing from the postprobe learner, replacing it with a featureless \`blind\` token.
3. **Randomized probe signal:** Execute the real source tool call and record its true output in evaluator-only audit; pass an *independent fair random* active/banned token to the postprobe actor. This is intentionally an artificial corrupted-observation control; it must not be misrepresented as the original source response.

After the policy tables are completely frozen, execute **48 fresh original source episodes per seed**, comparing all three trained actors with **five** separately executed fixed baselines (\`scripted_adaptive\`, \`always_probe_correct\`, \`always_stop\`, \`always_approve\`, \`always_reject\`) across both original source reviewer rules and each of \`unknown\`, \`certified\`, and \`resolved\` input regimes.

**Strongest baseline:** \`scripted_adaptive\` performs a real optional probe for unknown standing, acts directly from genuine verified cached standing for certified, and STOPs when already resolved. It is given exactly the engineered task-public regimes and predeclared rule; it is **not** a privileged original private-state oracle. \`always_probe_correct\` performs a real redundant probe in certified and resolved cases, and thus tests information-cost savings. Scripted-baseline action planning is not presented as agent learning.

The planned genuine selected original-source execution count is **5 seeds × (3 × 96 training + 48 fresh evaluation) = 1,680 source episodes**, each with both private original and separately revised terminal checkers (**3,360 private checker runs**). This is 1,680 reset source *episodes*, not 1,680 distinct independent tasks. No unopened original dev or sealed test families are used.

## Independent source-evidence admission and scientific disposition

**Protocol-integrity recovery:** An exploratory preadmission source run used 24 forced unknown probes despite the original immutable Q v1 manifest specifying **12**. Its real source observations were useful for debugging but are **NOT admissible as preregistered Q v1 scientific evidence**. A newly added exact-byte source-task spec reader and independent gate exposed this mismatch. The Q v1 manifest was **not** rewritten post hoc; the runner, gate and tests were corrected to the original frozen 12-probe protocol. The first candidate also encountered a recoverable 30-second Docker corrected-private-checker timeout; only that exact private input is eligible for up to three bounded 120-second checker replays, with replay count and actual elapsed time independently gated. Checker-invalid or changed-state results remain errors; no valid-zero substitution. The final scientific claims require fresh complete source replay from the corrected exact PR head, and are not based on the exploratory 24-probe run.

The independent gate reconstructs all seeded source scenario schedules, stage-0 behavior propensities, forced probe exploration, randomized probe signals, conditional stage-1 action/propensities and both frozen action-value tables solely from source-selected actual terminal scalars. It checks every original tool-call sequence, provenance hash, selected status, actual source terminal state class, unchanged original 9-check numerator and separately versioned corrected reward, paid probe costs and physical timestamps. Hostile tests reject unexecuted/forged probes, private-state leakage flags, forged source status, wrong original checker numerator and reward, modified frozen scorer, injected unchosen outcomes and illegal option transitions.

**Preregistered falsification tests:** Does the true probe-conditional learner reliably exceed fixed always-probe, always-STOP, constant-direct and zero/random observation controls? Does it choose to probe *selectively* (more in unknown than certified/resolved)? Does its *learned* postprobe action depend on the actual selected original source account status? Does it improve over the strongest scripted adaptive rule? If that transparent script is already optimal, **matching without exceeding it is the expected ceiling**, not evidence of general introspection. An advantage only under engineered masking is a fact about the masked benchmark, not natural source-native information discovery. Missing genuine held-out source families and model-FLOP accounting keep parent issue #466 open.
