## Scientific obligation and corrective strategy

R physically executed 855 real source-native source worker/checker episodes across three original TRAIN executable families, trained after an actually selected public first probe, and found that *all* native first probes yielded action-needed statuses. Blind and randomized observation signals performed identically; a strong original public direct script achieved the same held-out native reward with fewer selected source tool calls. S surveyed actual original TRAIN product review moderation (2151) and conditional bookmark tags (2001), obtaining three genuine different review interventions but **zero pure unchanged pending reviews**, and five absent requested tags but **zero already-present requested tags**. T surveyed original TRAIN cart (1549), geo subscriptions (1900), clinical enrollment (5) and bookmark folders (2000), encountering an unlinked requested cart ID, one new geo subscription, suspended enrollment requiring withdrawal, and missing requested folders. None supplied an actual action/authorized-no-action pair under **the same original task's conditional rule**. The T row 2000 shares the exact original bookmark executable class with S row 2001: S/T jointly added five distinct original TRAIN classes, not six; R adds three different ones. Thus R/S/T have eight known distinct original executable family classes, with no established natural same-rule contrast. Repeating them is wasteful.

The next bounded, falsifiable question is **how much of the full originally pinned TRAIN corpus even exposes a prospective public conditional and usable real source-public observations?** This is not yet a policy evaluation and does not warrant original-native private checker calls or five-seed learning. Public tool affordances, instructions containing “if” or “unless”, a returned unrelated record, an old existing record assigned a mutation, and a synthetic controlled negative state are not original-native evidence of an authorized no-op.

## Independent evidence and scientific claim limits

The independent U gate verifies the original byte-lock hash, 30/10/11 grouping, exactly 1,500 public TRAIN tasks surveyed (and zero DEV/TEST content exported), eight predeclared distinct source family/public user-prompt identities against earlier F source receipt SHA values, exact selected original public tool plan, declared required argument sets, time/RSS records, source-public reply digest and safe interpretation, no native checker or original source-private state forwarding, and absence of extra or missing unaccounted calls. Hostile fixture tests inject false public reply hashes, changed class/family/task identities, secret projection, illegal tool names, absent worker timing, fabricated source result status, invented no-op and changed experimental scope, and require rejection. An actual source-public lookup failure, missing identifier, truncated reply or unsupported declared schema is **unresolved**, not public evidence that a record is absent.

**This first U pass is an eligibility/custody census, not task-policy value-of-information testing.** The independent gate must not certify a natural same-rule action/no-action pair merely because a source tool returned objects, because a source prompt describes an \`if\`, or because some calendar/room/loan records are present and others absent. A later specific source-based task/observation-target matcher must demonstrate both states under the same originally authorized action conditional, ideally within multiple original TRAIN task instances naturally initialized differently, with independent unexamined mechanism classes held out. Only then should the programme spend original private terminal-native-checker costs and multi-seed learning, compared with direct/conditional source-public baselines and physical model compute.
