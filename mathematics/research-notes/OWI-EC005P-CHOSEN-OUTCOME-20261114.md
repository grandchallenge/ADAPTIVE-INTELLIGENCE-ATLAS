## Actual chosen-only learning experiment

The single programmatic tool wrapper discovers the target professional/review and user account status using **actual public original source tools**, with an original fresh-state reset every episode. It executes a predeclared read-tool sequence, presents *only* observed author account status and observed review moderation status to the learner, and lets the learner select exactly one of \`stop\`, \`approved\`, \`rejected\`. The public target finder and original-tool argument planner are scripted, **not learned**. Source-private state, class code, original checker/checklist, revised checker rules, target scoring label, expected action, task-rule identity and unchosen action rewards are **never** policy features.

An on-policy \`OnPolicyBandit\` estimates empirical chosen scalar option value by context. Its action-space prior is initially uninformative; it forces at least two genuine source outcomes per option per observed public context before \`epsilon=0.18\` continued exploration, then compares accumulated chosen-only mean terminal utility. Objective per episode: **real revised v1 terminal reward − 0.002 × actually selected source tool calls**. The heuristic cost coefficient is explicit and is not hardware FLOPs or measured energy. Source/terminal checker wall times, actual selected public tool receipts, number of calls and source worker peak RSS are separately recorded.

Training is **60 actual original-state reset episodes per independent mode**; 30 visits each to the source-public banned-author pending-review and active-author pending-review cases, with five seeds \`[11,23,37,41,53]\`. Every action is selected before its source terminal reward is observed, and the action policy is updated only after its chosen source episode is complete. Three independently retrained modes:

1. **True chosen-only feature/reward:** public account/status context available; the update uses the chosen action's actual corrected terminal score.
2. **Zero-information:** both public statuses are collapsed into a single \`blind\` feature, retaining otherwise identical actual chosen-source reward access.
3. **Shuffled chosen-outcome credit:** the learner has true public context but receives an independently selected *prior episode's actually chosen scalar* at update time rather than the present action's scalar. The exact source episode of this deliberately corrupted credit is retained and independently replayed. It is a temporal credit-assignment ablation, not a claim to a perfect global dataset permutation; it never introduces an unchosen counterfactual.

Every seed therefore executes **180 real on-policy source-training episodes**. The independent gate checks exact seeded action/propensity selection and scalar-credit history, original source-native numerator and corrected score formula, source-selected public read-call counts/hash receipts, real wall times and RSS, and equality of the frozen learned action table to its actual chosen-only updates. All negative claims must remain explicit; synthetic unit fixtures cannot substitute for source replay.

## Prospective, genuinely executed post-training comparisons

After each model is frozen, evaluate each of the three separately trained policies **against four strong fixed baselines**: always STOP, always APPROVE, always REJECT and **public-rule-correct** (a scripted account-status-dependent action that directly executes the task-public correct status). Each is executed on the same original source class and evaluated by both distinct terminal checkers, never supplied as a counterfactual during training. All comparisons occur in two stages:

- **Initial pending:** Original source reset and direct chosen-option action; this is the same source-task type as training but fresh physical episodes.
- **Heldout postcorrection:** Start from a fresh original source reset and perform a correct **evaluation-only public-task scripted first-stage action**, then observe the *actual* new public status and let the frozen policy decide STOP, APPROVE or REJECT. This tests whether a learned initial-state action gate preserves a corrected state, with no postcorrect-state data in training. It is **NOT** independent source family transfer, and the setup script does not represent a learned repair.

Each stage has both source-public rules and each of seven learned/baseline policies, i.e. **28 fresh original-source evaluation episodes per seed**, not reused train labels. Five-seed total predeclared target: **900 training + 140 evaluation = 1,040 actually executed source episodes**, each with one unchanged original and one new corrected restricted private terminal checker (2,080 separate private checker runs). Evaluate initial pending corrected reward/utility versus the **strong public-rule-correct** policy; evaluate heldout postcorrection source fidelity and actual tool calls against *always STOP* and *public-rule-correct*. Out-of-family generalization remains untested. The gate and scientific note must report failures and negative results even if CI is green.

## Acceptance and interpretation

An actual source score exceeding always STOP or a blind constant policy is a weak result when a preauthored public-rule-correct script can fully solve the two reviewed target rules. No inference of introspection, learned error correction, causal self-model, problem-solving generality, text-based reasoning, five-family transfer or compute-optimality follows from a positive two-context bandit score. The more demanding requested OWI outcome-only reflective-cognition acceptance remains **OPEN** pending fresh independent-task and heldout-mechanism sources, stronger perturbation/control settings, genuine adaptive inspection and repair with information-cost advantages, and robust comparison to the scripted public-affordance baseline.
