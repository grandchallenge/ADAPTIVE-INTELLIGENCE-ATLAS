# OWI-EC-005P — Actual-source outcome-only option learning versus strong public-rule baselines

**Grand Challenge Labs; 14 November 2026.** Continues parent [OWI-EC-005 issue #466](https://github.com/grandchallenge/ADAPTIVE-INTELLIGENCE-ATLAS/issues/466) after protected OWI-EC-005O benchmark-correction [PR #481](https://github.com/grandchallenge/ADAPTIVE-INTELLIGENCE-ATLAS/pull/481).

**Preregistered scientific scope:** One original independently grouped TRAIN source family, two different publicly specified review rules, an explicitly *new* terminal scorer, five actual source-replay seeds, three independently retrained chosen-only online tabular policies, stronger source-public scripted fixed baselines and a within-source heldout **postcorrection state mechanism**. This is a limited experimental study of a learned *option gate*, not a language model, learned tool planning, counterfactual oracle, clinical moderation system or proof of self-awareness.

## Actual chosen-only learning experiment

The single programmatic tool wrapper discovers the target professional/review and user account status using **actual public original source tools**, with an original fresh-state reset every episode. It executes a predeclared read-tool sequence, presents *only* observed author account status and observed review moderation status to the learner, and lets the learner select exactly one of \`stop\`, \`approved\`, \`rejected\`. The public target finder and original-tool argument planner are scripted, **not learned**. Source-private state, class code, original checker/checklist, revised checker rules, target scoring label, expected action, task-rule identity and unchosen action rewards are **never** policy features.

An on-policy \`OnPolicyBandit\` estimates empirical chosen scalar option value by context. Its action-space prior is initially uninformative; it forces at least two genuine source outcomes per option per observed public context before \`epsilon=0.18\` continued exploration, then compares accumulated chosen-only mean terminal utility. Objective per episode: **real revised v1 terminal reward − 0.002 × actually selected source tool calls**. The heuristic cost coefficient is explicit and is not hardware FLOPs or measured energy. Source/terminal checker wall times, actual selected public tool receipts, number of calls and source worker peak RSS are separately recorded.

Training is **60 actual original-state reset episodes per independent mode**; 30 visits each to the source-public banned-author pending-review and active-author pending-review cases, with five seeds \`[11,23,37,41,53]\`. Every action is selected before its source terminal reward is observed, and the action policy is updated only after its chosen source episode is complete. Three independently retrained modes:

1. **True chosen-only feature/reward:** public account/status context available; the update uses the chosen action's actual corrected terminal score.
2. **Zero-information:** both public statuses are collapsed into a single \`blind\` feature, retaining otherwise identical actual chosen-source reward access.
3. **Shuffled chosen-outcome credit:** the learner has true public context but receives an independently selected *prior episode's actually chosen scalar* at update time rather than the present action's scalar. The exact source episode of this deliberately corrupted credit is retained and independently replayed. It is a temporal credit-assignment ablation, not a claim to a perfect global dataset permutation; it never introduces an unchosen counterfactual.

Every seed therefore executes **180 real on-policy source-training episodes**. The independent gate checks exact seeded action/propensity selection and scalar-credit history, original source-native numerator and corrected score formula, source-selected public read-call counts/hash receipts, real wall times and RSS, and equality of the frozen learned action table to its actual chosen-only updates. All negative claims must remain explicit; synthetic unit fixtures cannot substitute for source replay.

## Prospective, genuinely executed post-training comparisons

After each model is frozen, evaluate each of the three separately trained policies **against four strong fixed baselines**: always STOP, always APPROVE, always REJECT and **public-rule-correct** (a scripted account-status-dependent action that directly executes the task-public correct status). Each is executed on the same original source class and evaluated by both distinct terminal checkers, never supplied as a counterfactual during training. All comparisons occur in two stages:

- **Initial pending:** Original source reset and direct chosen-option action; this is the same source-task type as training but fresh physical episodes.
- **Heldout postcorrection:** Start from a fresh original source reset and perform a correct **evaluation-only public-task scripted first-stage action**, then observe the *actual* new public status and let the frozen policy decide STOP, APPROVE or REJECT. This tests whether a learned initial-state action gate preserves a corrected state, with no postcorrect-state data in training. It is **NOT** independent source family transfer, and the setup script does not represent a learned repair.

Each stage has both source-public rules and each of seven learned/baseline policies, i.e. **28 fresh original-source evaluation episodes per seed**, not reused train labels. Five-seed total predeclared target: **900 training + 140 evaluation = 1,040 actually executed source episodes**, each with one unchanged original and one new corrected restricted private terminal checker (2,080 separate private checker runs). Evaluate initial pending corrected reward/utility versus the **strong public-rule-correct** policy; evaluate heldout postcorrection source fidelity and actual tool calls against *always STOP* and *public-rule-correct*. Out-of-family generalization remains untested. The gate and scientific note must report failures and negative results even if CI is green.

## Source-locked live result: five independent seeds and all original checker pairs

The [initial full five-seed source replay and independent gating CI run 43655150939](https://github.com/grandchallenge/ADAPTIVE-INTELLIGENCE-ATLAS/actions/runs/43655150939) finished successfully, with all seed jobs **11, 23, 37, 41, 53** independently successful. All seeds passed their exact seeded causal chosen-action/propensity replay, original source/provenance and selected-public-receipt gate, frozen model table replay, v1 score formula/unchanged original native numerator, zero-feature ablation integrity, prior-actually-chosen-scalar miscredit and posttraining evaluation isolation. Genuine original source execution counted **900 training + 140 fresh prospective evaluation = 1,040 original source episodes**, each of which ran the unchanged original private terminal checker and separate v1 corrected private terminal checker after termination (**1,040 original + 1,040 corrected checker invocations**, 2,080 total). These are repetitions of two source-public task rules from **one** source family, not 1,040 distinct independent task families.

The learner trained all 60 chosen-only original source episodes in each independent ablation/mode; five distinct seeds therefore mean **five independently initialized action-exploration histories for each of three independently retrained policy modes**, not 15 unique external source families. Strong evaluation scripts and the postcorrection setup did not supply counterfactual information during learning.

For further calibration, the fixed always-STOP rule scored mean utility **0.001111** on original pending cases, always-APPROVE **0.004667**, and always-REJECT **0.010222**. The true bandit increased chosen-source reward above each blind fixed action, as would be expected from distinguishing two publicly available binary statuses. It matched the strongest *scripted public-rule-correct* baseline **exactly on all five seeds**, achieved the exact same source-private corrected mean reward **1.027778** and mean original native score **0.277750**, and required the exact same mean **six source tool calls per case**. The true learned policy has **zero observed utility or call-count improvement over the scripted correct rule** on these tasks. Because the task-public rule identifies the correct answer directly, this is learning a small known action association, not causal discovery of an introspective repair strategy.

**Evaluation-only heldout postcorrection state:** A new original source reset was first corrected using the **scripted** publicly stated rule, then the frozen actor observed the changed public state and chose a second action. This mechanism was excluded from learner training but belongs to the same original family. The true policy's default action for an unseen context is STOP, so it retained the correct state in **10/10** actual source evaluations, mean utility **1.013777** and **seven** calls, equal to fixed always-STOP (also **1.013777**, seven calls) and only **0.002** above the scripted public-rule-correct reapplication policy (**1.011777**, eight calls). This apparent efficiency is fully explained by the explicit **unseen-context STOP default** and one fewer tool call, **not by learned introspective detection or repair**. The zero-feature retraining regressed on one seed's postcorrect cases, averaging **0.811155** utility across seeds, while miscredited-credit policies also reverted to the default STOP on unseen contexts and averaged **1.013777**. These results constrain the causal interpretation of any postcorrection success.

**Selected-only correctness and ablation meaning:** The source-native action selector never observes the source class/private initial/final state, checker source, original 9-check targets, revised evaluator or unselected outcomes. The actor receives the actually observed public account+moderation status at choice time and only the actually chosen corrected terminal scalar after its original source episode. For the miscredited-control mode, the "shuffled" assignment draws from **prior real chosen-action scalars** with a separately logged original episode index; it breaks current causal credit and is not a permutation of a hypothetical full counterfactual outcome table. In live results it performs much worse than true credit but with seed variability. A policy supplied no user/review-state context cannot in general solve both public rules simultaneously: four seeds chose a blind STOP and one chose a constant approval.

**Resource and evidentiary limitations:** Every original physical episode records selected public tool count and hashed replies, actual source-worker and each private-checker wall time, and worker-reported peak RSS. These are genuine container/device execution observations retained in the [five-seed CI artifacts](https://github.com/grandchallenge/ADAPTIVE-INTELLIGENCE-ATLAS/actions/runs/43655150939); the tabular learner involves only three scalar action-value estimates and 60 online updates per mode, so no language-model FLOP or energy superiority has been established. The fixed coefficient 0.002 per tool call is **designed utility**, not measured hardware cost. The two public rules were known to the scripted planner, and the corrected reward was engineered expressly to separate correct/STOP/prohibited terminal states. The actual original native scorer still does **not** penalize an initially wrong original moderation state below untouched STOP.

**Scientific disposition:** \`FIVE_SEED_REAL_SOURCE_CHOSEN_ONLY_CONTEXTUAL_ASSOCIATION_LEARNED; ZERO_OR_SHUFFLED_CREDIT_DEGRADES; STRONG_SCRIPTED_PUBLIC_RULE_NOT_BEATEN; HELDOUT_POSTCORRECT_ADVANTAGE_NOT_LEARNED; REFLECTIVE_CAUSAL_IDENTIFICATION_UNPROVED\`. This is substantive execution and rigorous negative discrimination, not an OWI closure result. The next work must introduce genuine hidden/action-ambiguous public states where active observation is informative, train a conditional post-probe policy, and compare additional observation against direct/fixed scripted actions with real cost, five seeds and an independently held-out source task/family. It must not relabel the versioned terminal reward as the original evaluator or count scripted agent logic as learned policy planning.

## Acceptance and interpretation

An actual source score exceeding always STOP or a blind constant policy is a weak result when a preauthored public-rule-correct script can fully solve the two reviewed target rules. No inference of introspection, learned error correction, causal self-model, problem-solving generality, text-based reasoning, five-family transfer or compute-optimality follows from a positive two-context bandit score. The more demanding requested OWI outcome-only reflective-cognition acceptance remains **OPEN** pending fresh independent-task and heldout-mechanism sources, stronger perturbation/control settings, genuine adaptive inspection and repair with information-cost advantages, and robust comparison to the scripted public-affordance baseline.
