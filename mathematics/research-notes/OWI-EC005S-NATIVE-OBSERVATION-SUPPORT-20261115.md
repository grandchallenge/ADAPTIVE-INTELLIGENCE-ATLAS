**Grand Challenge Labs, 15 November 2026.** Research successor to protected [OWI-EC-005R PR #492](https://github.com/grandchallenge/ADAPTIVE-INTELLIGENCE-ATLAS/pull/492) and parent [OWI-EC-005 issue #466](https://github.com/grandchallenge/ADAPTIVE-INTELLIGENCE-ATLAS/issues/466).

## Scientific motivation

R trained outcome-only CONTINUE/STOP after a real public probe on original distinct TRAIN source families 0 and 2, and evaluated it on a distinct original TRAIN family 3. All 240 source-public training probes per mode across five seeds returned the *same* action-needed status. Every learner, including blind and randomized-signal ablations, therefore chose CONTINUE. On the held-out family 3 a source-native direct action without probing achieved the identical task reward at lower tool-call cost. R proved useful fixed-action transfer across genuine executable source families, **not** learnable information valuation or reflective abstention. Repeating these positive-only cases is scientifically and operationally wasteful.

The next falsifiable prerequisite is a cohort that **naturally contains both action-needed and abstention/no-op source-public observations**, using the original unmodified task, originally advertised tools, and unchanged original initial environment. This S tranche isolates and answers that necessary *data support* question **before** spending any original private checker or learning budget. It never counts preauthored source instructions alone as observed data.

## Precommitted physical probe sequence and classifications

All source read actions are **actually executed**. The public-only survey begins at native product review row 2151 with original \`list_all_products()\`; for each of up to ten returned existing products, it invokes the original \`get_reviews_for_product_by_status(product_id, moderation_status="pending")\`, and for each pending review within its first twelve records per product it resolves the author’s account status via the original \`get_user_by_id\` (up to twenty distinct authors). Tool arguments are derived only from the original previous **selected** public reply, never from original source-private state or checker. It classifies the returned review using the original task rule into \`approve\`, \`reject\`, \`edit_rating_and_leave_pending\`, \`leave_unchanged\`, or \`unresolved\`. A malformed, truncated, nonauthoritative or failing status lookup must not be misclassified as absence. The finite sample cap is explicit: even finding all branches within those selected records would not prove the entire native task family has a representative population.

It then invokes \`list_tags()\` on the independently selected original bookmark-family row 2001. It checks only the **five exact tag names from that original public task**: \`tcm\`, \`herbal\`, \`acupuncture\`, \`evidence-based\`, \`safety\`. Each is classified as an original public list entry that is already present (therefore no create warranted) or absent (therefore creation is a *candidate* under the user’s public instruction). Source-public list lookup failures must never be interpreted as “tag absent.”

The predeclared source-native support criteria are separately evaluated: for 2151, **at least one genuine source pending review each in approve, reject, and leave-unchanged classes**; for 2001, **at least one naturally existing and at least one missing target tag**. The special review edit is reported separately. These are operational evidence thresholds, not a native-checker task-completion metric. Finding either qualifies a *candidate cohort* for future selected-outcome learning; it does **not** satisfy parent #466.

The exact selected public tool response strings, SHA256 digests, actual tool/container time, worker RSS, invocation order and bounded original public task/class source identities are recorded. The independent gate replays all classifications directly from the original selected public responses and rejects injected source status, fabricated read calls, changed original source class, illegal write tools, mismatched response hashes, private-state leakage flags, absent physical timing, forged review approval/abstention labels and nonreproducible tag existence. No gold answers or off-policy unchosen terminal outcomes are available, because **no private checker runs at all**.

The survey is **deterministic and intentionally narrow**, not a train/evaluation split. It makes at most 40 public read-only source tool calls and never changes source state. The user-facing evidence should separately report product count, pending original reviews, category support, tag existence, and how many actual calls were necessary. All original source public entries are synthetic benchmark data. Any eventual held-out family/mixed-mechanism learning protocol must be frozen in a future work item **after** this support-only cohort selection; the S selected source families cannot be presented afterward as a blinded discovery set.

The source-native review categories are concrete, not hypothetical: an active account's 4-star Electronics review is eligible for **approve**; a suspended author's 1-star Furniture review requires **reject**; and an active account's 4-star Home review containing “refills” requires **rating edit, still pending** under the original task policy. The source-public user-account lookup, rating, product category and original pending status—not a source-private class, checker, label or revised O/Q scorer—are what determine each classification. No source state was mutated in the survey.

**Crucial negative:** Row 2151's public *instruction* “leave all other pending reviews unchanged” describes a legal abstention branch, but the actual original source state had **no such pending review among the selected source records**. The Home/refill exception is **not** a no-op: it orders an actual rating edit, although moderation remains pending. Counting it as successful abstention would be a false positive. Row 2001 similarly has a legitimate create-if-missing rule, but all requested original target tags were absent: the existence of five *different* tags in the public database must not be misreported as an already-present requested target.

The preregistered criteria demanded either (i) an actual original review in each of the approve, reject and **leave-unchanged** categories, or (ii) both missing and **already-existing requested** tags. The independent source-public replay gate correctly recorded both as **false**, and the full cohort \`qualifying_natural_mixed_observation_cohort_found=false\`. All original source tool responses, exact ordered arguments, hashes, physical times and worker RSS are in the job's 30-day evidence artifact. No independent original private native checklist was executed, **zero** terminal task reward was measured, and no learned actor or causal-effect estimate was attempted.

**Scientific interpretation:** The native review environment supports three different legally authorized **interventions**, making it a concrete candidate for later multiclass action conditioning. It does **not** yet support genuine chosen-vs-abstain training on this unmodified source state. The tag environment supports real source-native create-if-missing **actions** but no naturally satisfied requested tag. The dataset availability obstruction found in R persists across these two newly inspected natural original TRAIN tasks, albeit with richer *action-action* variation in the review family. Neither result is transferable proof that all 30 original TRAIN source families lack usable clean cases.

Do not run expensive five-seed learning merely because a public task *describes* a possible no-op branch.

## Scientific interpretation and boundary

A positive mixed-observation finding answers the *existence of data support in at least one original native training family* and supplies an evidence-locked design substrate for active identification. It is not an observed learned controller, not a causal effect estimate of the probe relative to a no-probe policy, and not an advantage over a strong source-public script or native checker. Negative outcomes must be documented without posthoc task masking or changing the original initial state. In either case the parent issue remains OPEN: actual outcome-only policy learning, repeated seeds, genuinely withheld source mechanisms, original native terminal score, strong baseline comparison and physical model-compute measurements are still required.

**Admission boundary:** Original-source CI source tool calls and independent gate, critical scoped review, final exact-head CI including Atlas \`validate\`, and protected SHA readback must complete before stating a protected finding.
