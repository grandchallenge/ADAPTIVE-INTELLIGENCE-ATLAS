## Contract

Formalize the value of preserving future viable actions and recoverability under uncertainty without redefining regret to contain those properties.

## Opening obstruction

Two policies can have:

- the same immediate reward;
- the same prior expected return;
- the same Bayesian regret;

and still leave radically different ability to correct after new evidence arrives.

Therefore an action-value gap or prior-average regret need not exhaust the decision-relevant structure of future flexibility.

The chapter must make that residual structure explicit.

## Core finite decision object

Use:

- latent environment `theta in Theta`;
- belief `b(theta)`;
- current state `s`;
- admissible action set `A(s)`;
- transition `T(s,a,theta)`;
- hard viability constraint set `K`;
- remaining horizon `h`;
- post-evidence target or utility family `U_theta`;
- optional correction-cost functional `c_corr`.

A future continuation is viable only when it respects the declared constraints over the declared horizon.

## Viable continuations

Let `Pi_h(s)` be the admissible continuation policies from `s` for the remaining horizon.

Define the viable subset

`V_h(s)
=
{pi in Pi_h(s): the constrained trajectory generated by pi remains in K over h}`.

This is a feasibility object, not a value function.

## Functional option classes

Raw action count is representation-sensitive.

Let `G_s(pi)` denote the declared consequence signature of a viable continuation.

Define

`pi ~_s pi'`

when

`G_s(pi)=G_s(pi')`.

The functional option set is

`O_h(s)=V_h(s)/~_s`.

The chapter may report `|O_h(s)|` only when the consequence signature and horizon are declared.

## Correction cost

After evidence identifies or updates the relevant environment, define

`k_h(s,theta)
=
inf_{pi in V_h(s)} c_corr(pi,theta)`

subject to satisfying the declared target for `theta`.

If no viable continuation reaches the target, set

`k_h(s,theta)=+infinity`.

This separates:

- hard loss of recoverability: `k=+infinity`;
- soft degradation: finite but larger `k`.

## Tolerance-indexed correction capacity

For tolerance `epsilon>=0` and belief `b`, define

`CC_{h,epsilon}(s;b)
=
sum_{theta in Theta}
b(theta) 1{k_h(s,theta)<=epsilon}`

for finite `Theta`.

This is the belief mass of environments for which correction remains possible within the declared tolerance.

For continuous environment classes, the sum may be replaced by the corresponding probability measure.

## Optionality is not uncertainty aversion

The chapter must distinguish:

- preserving response alternatives;
- preferring low-variance outcomes;
- delaying action;
- maintaining reversibility;
- acquiring information.

A policy may preserve options while taking substantial risk.

A policy may be conservative while irreversibly destroying future alternatives.

## Information versus correction

Information gain concerns what is learned.

Correction capacity concerns what remains feasible after learning.

Perfect observation can coexist with zero correction capacity for some environments.

## Policy optionality versus environment optionality

Policy optionality is the set of distinct viable continuations available to the decision maker.

Environment optionality is exogenous branching in what the world may do.

More environmental branches do not imply more controllable options.

## Irreversibility and recoverability

An action is operationally irreversible over horizon `h` relative to target set `B` when no admissible continuation can return the resulting state to `B` within `h`.

Irreversibility is therefore always relative to:

- state abstraction;
- target/equivalence set;
- constraints;
- horizon.

A stochastic bad outcome is not automatically irreversible, and an irreversible action need not have a bad immediate outcome.

## Exact witness

Let

`Theta={L,R}`

with prior

`b(L)=b(R)=1/2`.

At stage 0 compare:

- `P`: preserve flexibility, pay immediate cost `1/2`, then retain both terminal actions `{L,R}`;
- `C_L`: commit left, pay no immediate cost, then retain only `{L}`.

At stage 1 the environment is revealed perfectly.

Terminal reward is:

`u_theta(a)=1` if `a=theta`, otherwise `0`.

Policy `pi_P` preserves, then matches the revealed environment.

Policy `pi_L` commits left.

Returns:

- `G(pi_P,L)=1/2`;
- `G(pi_P,R)=1/2`;
- `G(pi_L,L)=1`;
- `G(pi_L,R)=0`.

Therefore both have prior value

`1/2`.

Against an environment-informed comparator with value `1` in each environment:

- `Reg(pi_P,L)=Reg(pi_P,R)=1/2`;
- `Reg(pi_L,L)=0`;
- `Reg(pi_L,R)=1`.

Both have Bayesian regret

`1/2`.

Yet after stage 0:

- `O_1(s_P)={L,R}`;
- `O_1(s_L)={L}`.

With zero correction cost for the matching terminal action and infinity when the matching action is infeasible:

- `CC_{1,0}(s_P;b)=1`;
- `CC_{1,0}(s_L;b)=1/2`.

Both branches receive the same perfect one-bit observation of `theta`.

Thus information gain is equal while correction capacity differs.

## Cost counterexample

Replace the preservation cost `1/2` by `c`.

Then:

`Q(P)=1-c`.

The left commitment remains:

`Q(C_L)=1/2`.

For `c>1/2`, preservation has more functional options and greater correction capacity but lower expected return.

Therefore optionality is not a universal injunction against commitment.

## Alias counterexample

Suppose one state exposes two action labels whose transitions, costs, and future consequence signatures are identical.

Raw action count doubles.

Functional optionality does not.

Therefore action count without consequence equivalence is not a robust optionality measure.
