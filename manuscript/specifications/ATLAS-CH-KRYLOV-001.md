## Core definitions

For square operator A, starting residual r0, and m >= 1,

K_m(A,r0) = span{r0, A r0, ..., A^(m-1) r0}.

For Ax=b and starting point x0, let r0=b-Ax0 and seek xm in x0 + K_m(A,r0).

Arnoldi uses an orthonormal basis relation A V_m = V_(m+1) Hbar_m with Hbar_m upper Hessenberg.

For symmetric or Hermitian A, Lanczos is the exact-arithmetic short-recurrence specialization with a symmetric tridiagonal projected matrix.

## Projected solve distinctions

Galerkin requires residual orthogonality to the trial space. Minimum-residual methods minimize the Euclidean residual norm. Residual minimization and error minimization are distinct.

For nonsingular A, e_m=A^(-1) r_m, so residual-to-error interpretation depends on conditioning.

## Exact witness

Use A=diag(1,2,4), b=(1,1,1)^T, x0=0.

For K_2=span{b,Ab}, use V=[b,Ab]. Then

V^T A V = [[7,21],[21,73]],
V^T b = [3,7]^T,
c = [36/35,-1/5]^T.

Hence

x2 = [29/35,22/35,8/35]^T,
r2 = [6,-9,3]^T / 35,

with V^T r2 = 0 and ||r2||_2^2 = 18/175.

Replay the same example with an orthonormal Lanczos basis.

## Conditioning control

Use Ac=diag(1,100,10000), b=(1,1,1)^T, x0=0.

The one-dimensional SPD Galerkin/CG step has alpha=1/3367 and Euclidean residual norm squared 19602/3367 > 3 = ||r0||_2^2.

Use this only to show that a valid CG step need not reduce Euclidean residual norm, because CG minimizes the A-norm of the error over its affine Krylov space.

## Preconditioning and matrix-free access

Distinguish left and right preconditioning. State that preconditioning changes the effective operator. Classical Krylov iteration can operate through repeated operator-vector products without explicit dense matrix formation.

## Finite precision and failure boundaries

Exact-arithmetic orthogonality is not an unconditional finite-precision guarantee. Discuss reorthogonalization, restarting, and storage/orthogonalization costs.

Do not conflate:
- arbitrary subspaces with Krylov spaces;
- small residual with small error;
- Arnoldi with Lanczos assumptions;
- iteration count with preconditioning;
- classical Krylov theory with later learned nonlinear transport.
