# A Mathematical Atlas of Adaptive Intelligence — v0.1.0

This is the first governed public release of *A Mathematical Atlas of Adaptive Intelligence*.

## Release structure

- Canonical source of truth: LaTeX
- Primary presentation artifact: PDF
- Broader-accessibility artifact: HTML

The final `v0.1.0` artifacts are a byte-preserving promotion of the independently audited release candidate `atlas-v0.1.0-rc.1`.

## Scope

- 80 canonical chapters
- 126 hard dependency edges
- 18 registered/rendered figures
- 85 source records
- 175 bibliography keys
- HTML includes all 18 figures with descriptive alt text

`ATLAS-CH-MECHDIAG-001` is intentionally presented as the concise interlude **From Readability to Functional Evidence**.
