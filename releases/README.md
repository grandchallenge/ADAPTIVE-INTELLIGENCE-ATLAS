# Releases

This directory is reserved for governed release artifacts.

No public release is authorized while the repository `LICENSE` remains in `LICENSE SELECTION PENDING` state.

Release promotion requires, at minimum:

1. explicit Human Steward license selection;
2. exact protected release commit/tag;
3. version/date citation metadata bound to that tag;
4. rendered-format validation;
5. exact artifact hashes and release manifest;
6. release-candidate audit;
7. explicit public-release authorization.

The existence of a build artifact or a green repository validation run does not by itself confer publication-ready, final-copy, certified, or released status.
